# ADR 0033: Atlas Rendering iteration-2 authored slice

- Status: Accepted
- Date: 2026-08-15
- Scope: calendar binding, atlas presets, authored/semantic overlays, bitmap labels, political style

## Decision

Literal authored years are converted to physical offsets in `daena-core`, not
by JavaScript `Date`. The optional `maps` field `physicalCalendarBinding`
records `calendarId`, `calendarReferenceYear`, `physicalOffsetAtReference`, and
`hasYearZero`. Year `0` is rejected when `hasYearZero` is false. BCE years are
signed negatives (`-1` is 1 BCE). The normalized render request always stores
the resolved `offsetYears` plus the authored selection and binding revision
when a calendar year was used.

`atlasPresets` is a separate schema-version-`1` `maps` field. Preset records
contain no destination path, job ID, cache key, or generated bytes. Updates use
the existing field revision and request-ID mutation contract.

Authored vector features and semantic location anchors are resolved into the
immutable snapshot. Missing layer IDs, filtered validity intervals, and
omitted labels are reported in snapshot diagnostics and provenance.

Labels use the hashed Apache-2.0 bitmap font `daena-atlas-bitmap-5x7`. A
pinned TTF/shaper remains deferred until a licensed hashed TTF file is added;
iteration 2 does not fetch fonts or depend on HarfBuzz.

Style `daena-atlas-political` is bundled. Renderer version is `3`.
